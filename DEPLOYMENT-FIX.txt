KHETMITRA - NEXT.JS BUILD DIRECTORY FIX

This project uses the Next.js App Router. The required route files are:
  app/page.tsx
  app/layout.tsx

IMPORTANT: Set your hosting platform's Project Root / Root Directory to the folder that contains BOTH package.json and the app folder. Do not set it to public, components, app/api, or a parent folder that only contains the extracted project folder.

For Vercel:
1. Open Project Settings -> General -> Root Directory.
2. Select the project folder containing package.json and app/ (use ./ if the project files are at repository root).
3. Save, then redeploy.
4. Use `pnpm install` for install and `pnpm run build` for build.

If uploading a ZIP, extract it so package.json and app/ are side by side, then deploy that folder.

The source archive already contained app/page.tsx and app/layout.tsx. The reported error therefore points to the build running from a different directory, not to a missing route file.
